# КР — контрольная работа (Асеев Н.С.), тема 17

**Тема 17.** Разработка паттерна для обеспечения безопасности приложения при угрозе потери информации вследствие несогласованности работы узлов хранилища больших данных.

В этой папке лежит контрольная работа: Django-приложение **KR_Aseev** — мини-дашборд в стиле Grafana для кластера хранилища из 5 узлов.

- Адрес в реплике: `/kr/`.
- Строки ввода: поток записи, задержка репликации, рассогласованные записи и узлы в строю (по часам); кнопка «Обновить» пересчитывает 6 графиков и 2 таблицы.
- Расчёты и выбор реакции паттерна выполняет сервер Django (API `/kr/api/metrics/`), графики рисует Chart.js.

Паттерн: журнал упреждающей записи (WAL) + кворумная запись (W = 3 из 5) + сверка реплик (read repair) + безопасная остановка записи при потере кворума.

Структура:

- `views.py` — представления `index` (страница) и `metrics_api` (расчёты и реакция паттерна в JSON);
- `urls.py` — маршруты приложения;
- `templates/KR_Aseev/base.html` и `index.html` — шаблоны страницы.
